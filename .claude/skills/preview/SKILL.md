# 預覽

1. 如果還沒安裝套件（沒有 node_modules），先執行 `npm install`。
2. 在**背景**執行 `npm run dev`，不要讓它卡住對話。
3. 告訴使用者打開 http://localhost:3000 ，並說明：
   - 首頁是主星；拖曳可以旋轉星系
   - 點選自己的城市，鏡頭會飛過去，下方就是他設計的頁面
   - 存檔後瀏覽器會自動更新
4. 如果終端機出現錯誤，用白話解釋原因，只修改使用者自己城市資料夾內的檔案。
