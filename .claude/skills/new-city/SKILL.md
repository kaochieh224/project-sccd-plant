# 建立作品入口（領取地塊）

1. 取得使用者的 GitHub 帳號：先試 `gh api user --jq .login`，失敗就直接問使用者。帳號一律轉小寫。
2. 確認 `cities/<帳號>/` 不存在；已存在就告訴使用者，改成協助他繼續編輯。
3. 執行 `npm run new-city -- <帳號>`，告訴使用者：「你在星圖上領到了一塊地，地塊位置由你的帳號決定。」
4. 用**選擇題**一次問完以下問題（每題附預設值），再依回答填寫 `city.json`：
   - 預設 3D 模型的規模：一棟房子／村落／城鎮／大都市（預設：村落）。之後自己寫 City.ts 時可以完全不受這個限制
   - 作品名稱（16 字內）
   - 一句話作品描述：觀眾在這件作品前會做什麼？（40 字內，寫進 oneLiner）
   - 主色（給 4 個 hex 色票讓他選）
5. `scenes` 先保留範本的兩站，告訴使用者之後會一起設計穿梭機路線。
6. `work.json` 的欄位（方向、觀眾、主攻賽事、非傳統三問、目前階段）用使用者的話整理，內容從他的 PLAN.md 來，不要替他想作品或回答三問；資訊不足就保留範本提示文字，並提醒他之後補上。展示頁與 repo 網址（showcaseUrl、repoUrl）W4 起再填。
7. 把使用者的回答寫進 `cities/<帳號>/CLAUDE.md` 的「我的作品」與「這個地塊的想像」。
8. 執行 `npm run check`，通過後提醒使用者執行 `/preview`，在星圖上找到自己的光點。
