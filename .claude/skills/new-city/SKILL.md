# 建立新城市

1. 取得使用者的 GitHub 帳號：先試 `gh api user --jq .login`，失敗就直接問使用者。帳號一律轉小寫。
2. 確認 `cities/<帳號>/` 不存在；已存在就告訴使用者，改成協助他繼續編輯。
3. 執行 `npm run new-city -- <帳號>`，告訴使用者：「你在星球上領到了一塊地，地塊位置由你的帳號決定。」
4. 用**選擇題**一次問完以下問題（每題附預設值），再依回答填寫 `city.json`：
   - 城市規模：一棟房子／村落／城鎮／大都市（預設：村落）——之後自己寫 City.ts 時可以完全不受這個限制
   - 城市名稱（16 字內）
   - 善意企劃一句話：想為誰、做什麼好事？（40 字內）
   - 主色（給 4 個 hex 色票讓他選）
5. `scenes` 先保留範本的兩站，告訴使用者之後會一起設計穿梭機路線。
6. `proposal.json` 的其餘欄位（對象、問題、行動、改變、步驟）用使用者的話整理，不要替他編造企劃；資訊不足就保留範本提示文字，並提醒他之後補上。
7. 把使用者的回答寫進 `cities/<帳號>/CLAUDE.md` 的「我的善意企劃」與「城市的想像」。
8. 執行 `npm run check`，通過後提醒使用者執行 `/preview`，在星球上找到自己的城市。
