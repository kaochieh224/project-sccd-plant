# 燈塔港：給 Claude Code 的說明

## 我的善意企劃
- 我想幫助的對象：第一次寫程式、第一次用 GitHub 的同學
- 我想做的事：一座會回應你、但不會責備你的燈塔
- 為什麼是這件事：多數人放棄寫程式，是因為第一次的挫折沒有人接住

## 城市的想像
- 規模：村落。一個小港口就夠了，重點是那座燈塔。
- 登陸後的第一印象（顏色、氣氛、聲音、材質）：白與紅的燈塔、黃色的光、安靜的海。子 UI 用瑞士平面設計風格，和主星形成對比。
- 穿梭機站點：港口全景 → 碼頭 → 燈塔下 → 燈室
- 參考作品或關鍵字：港口燈塔、瑞士國際主義平面設計

## 我希望 Claude Code 怎麼協助我
- 這是給同學參考的示範城市，程式碼要好讀、註解要清楚
- 不要引入額外套件

## 我已經做到的（每次上課後更新）
- 3D 燈塔港（City.ts）、跟著站點改變的標題、自己排版的企劃區、送光按鈕
