# 01　建立你的城市

## 先理解這個網站的結構

```
善意星系
├── 背景：3D 星球、北極太空港、航線、雲        ← 全班共用，透過框架提案才能改
├── 母 UI：導覽列、穿梭機面板、城市導航         ← 全班共用，透過框架提案才能改
└── 你的城市  cities/<你的帳號>/                ← 你是市長
    ├── city.json      城市識別＋穿梭機站點   ← 公版欄位，內容自己填
    ├── proposal.json  善意企劃               ← 公版欄位，內容自己填
    ├── City.ts        3D 城市模型            ← 完全自由（選用，但這是重頭戲）
    ├── Page.tsx       降落後的子 UI          ← 完全自由
    └── CLAUDE.md      設計意圖               ← 寫給 Claude Code 看
```

**受限的框架，自由的填充**：所有人用同一套欄位，主星才能把大家放上同一顆星球、讓穿梭機知道要停哪裡、彙整全班的企劃；欄位以外的一切都由你決定。

> 你**不能**選地塊的位置。位置由你的 GitHub 帳號計算出來，就像你無法選擇自己出生在哪裡。偶爾有新同學加入時，少數城市會搬到隔壁的地塊；你的城市與站點是以城市中心為原點，搬家也不會壞。

每次打開 Claude Code，它都會列出你的任務進度並引導下一步。輸入 `/mission` 隨時查看。

---

## ① city.json：你的城市是誰

| 欄位 | 說明 | 範例 |
|---|---|---|
| `name` | 城市名稱，16 字內 | `"燈塔港"` |
| `owner` | 市長（你的名字） | `"高捷"` |
| `goodwill` | **善意企劃一句話**，40 字內，會顯示在星球上 | `"為第一次寫程式的人，點亮一座不會責備人的燈塔。"` |
| `color` | 主色，6 碼 hex | `"#4d96ff"` |
| `scale` | `"house"` 一棟房子、`"village"` 村落、`"town"` 城鎮、`"metropolis"` 大都市 | `"village"` |
| `keywords` | 最多 3 個關鍵字，每個 10 字內 | `["引路", "示範"]` |
| `scenes` | 穿梭機站點，1–8 站（見 ③） | |

> 還沒寫 `City.ts` 之前，主星會依 `scale` 和 `color` 自動幫你長出一座預設城市，所以第一天就能出現在星球上。

## ② proposal.json：你的善意企劃

| 欄位 | 問自己 | 字數 |
|---|---|---|
| `title` | 企劃叫什麼名字？ | 24 |
| `audience` | 我想幫助誰？ | 40 |
| `problem` | 我觀察到他們遇到什麼困難？ | 120 |
| `action` | 我打算做什麼？ | 120 |
| `impact` | 做完之後，希望發生什麼改變？ | 120 |
| `steps` | 1–3 個執行步驟 | 每步 40 |
| `status` | `"構想"`、`"原型"`、`"測試"`、`"完成"` | — |

> 企劃的內容請用你自己的話寫。Claude Code 可以幫你修句子，但不能幫你想企劃。

## ③ 穿梭機站點 scenes：參觀者會看到什麼

降落你的城市後，參觀者搭著穿梭機，一站一站地參觀。每一站就是一個**鏡頭位置**：

```json
{ "name": "燈塔下", "camera": [34, 9, 40], "target": [0, 70, 0], "note": "抬頭看，光一直都在。" }
```

| 欄位 | 意思 |
|---|---|
| `name` | 站名，12 字內 |
| `camera` | 鏡頭站在哪裡 `[x, 高度, z]`：x、z 在 ±250 內，高度 1–500 |
| `target` | 鏡頭看向哪裡：x、z 在 ±250 內，高度 -50–500，不能和 camera 同一點 |
| `note` | 到站時顯示的一句話（選填，60 字內） |

座標以你的城市中心為原點，地面高度是 0。地塊半徑 120，建議蓋在高度 260 以內。最多 8 站。

**設計路線的訣竅**：像拍電影一樣想——先一個大全景（高、遠），再一步步靠近（低、近），最後停在你最想讓人看到的細節上。

```
請幫我設計 4 站的穿梭機路線：先從空中看整座城市，再降落到市集，
接著穿過兩棟大樓之間，最後停在屋頂的花園。
```

## ④ City.ts：親手蓋你的城市

把範本裡的 `City.example.ts` 改名為 `City.ts`，然後告訴 Claude Code 你想蓋什麼：

```
我的城市是一棟很大的樹屋，樹枝上掛著很多會發光的信箱
```
```
做一座賽博龐克都市：很高的大樓、霓虹招牌、高架軌道上有列車在跑，
有人來參觀時，招牌會一個一個亮起來
```
```
我只想蓋一間小小的深夜麵攤，但要很精緻：攤車、燈籠、冒煙的鍋子、三張板凳
```

一棟房子到一整座都市都可以，尺度由你決定。還有三件事要知道：
- **會動**：`update(t, dt, info)` 每一格畫面都會執行，可以讓東西轉、飄、閃
- **會回應參觀者**：`info.visited` 是「有沒有人在參觀」，`info.scene` 是「停在第幾站」
- **壞了不會連累別人**：City.ts 出錯時，主星會自動改用預設城市

## ⑤ Page.tsx：降落後的子 UI

鏡頭飛進你的城市後，畫面上疊著的就是你的 `Page.tsx`，整個頁面由你設計。

主星提供幾個零件（`@/kit`），可用可不用：

| 零件 | 作用 |
|---|---|
| `<Sky>` | 透明的天空窗，露出背後的 3D 城市；滑鼠可以穿透去拖曳環顧（要放在最外層） |
| `<Nameplate>` | 城市名牌 |
| `<SceneList>` | 穿梭機站點清單，點一下就飛過去 |
| `<ProposalBoard>` | 標準企劃看板 |
| `<Ground>` | 白色實心區塊 |
| `useShuttle()` | 知道參觀者停在第幾站、控制穿梭機（`go(i)`、`next()`、`prev()`） |

範本用了這些零件。老師的示範城市 `cities/kaochieh224/`（燈塔港）則示範了：標題跟著站點改變、自己排企劃、和主星完全不同的視覺風格。

### 和 Claude Code 對話的訣竅

| ✗ 太模糊 | ✓ 具體 |
|---|---|
| 「幫我做好看一點」 | 「企劃區改成左右兩欄，左邊大標題，右邊用編號列出問題、行動、改變」 |
| 「城市加點東西」 | 「在第 2 站的廣場中間加一座噴水池，水會一直往上噴」 |
| 「改顏色」 | 「整座城市改成黃昏的感覺：橘色和紫色，窗戶都亮著暖黃色的燈」 |

更好的做法：
1. **先要方向**：「給我三種方向，用文字描述就好，先不要寫程式」
2. **一次只改一件事**：改完、看過、滿意了，再提下一個要求
3. **看不懂就問**：「你剛剛改了什麼？為什麼要加 'use client'？」
4. **出錯就貼**：把錯誤訊息整段貼給 Claude Code
5. **養成習慣**：每次下課前請 Claude Code 更新你的 `CLAUDE.md`

## 規則（違反時，CI 會擋下你的 PR）
- 只能修改自己的資料夾 `cities/<帳號>/`
- 只能引用：自己資料夾內的檔案、`react`、`next/link`、`three`、`three/addons/…`、`@/kit`
- 樣式要寫在 `*.module.css`，不能用 `:global`
- 單一檔案 ≤ 2 MB，整座城市 ≤ 8 MB（圖片請先轉成 `.webp`）

隨時可以輸入 `/check` 自我檢查。做好了就看 [02 送出 PR](./02-送出PR.md)。
