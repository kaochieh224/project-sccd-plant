# 00　從零開始

> 給第一次寫程式、第一次用 GitHub 的同學。照順序做完，大約 40 分鐘。
> 卡住時：把整段錯誤訊息截圖，貼到課程群組，或直接貼給 Claude Code 問。

## 你會用到的東西

| 工具 | 是什麼 | 比喻 |
|---|---|---|
| **GitHub** | 放程式碼的雲端倉庫，全班共用一個 | 全班共用的雲端資料夾，但每次修改都有紀錄 |
| **Git** | 在你電腦上記錄修改的工具 | 遊戲的存檔系統 |
| **Node.js** | 讓網站能在你電腦上跑起來 | 網站的引擎 |
| **GitHub CLI（gh）** | 讓 Claude Code 幫你操作 GitHub | 遙控器 |
| **Claude Code** | 用聊天的方式寫程式的 AI 助手 | 坐在你旁邊、會寫程式的同學 |
| **終端機（Terminal）** | 打字下指令的視窗 | 跟電腦對話的地方 |

---

## 步驟 1　建立 GitHub 帳號
1. 到 https://github.com/signup 註冊。帳號名稱建議用英文小寫，**之後你的城市資料夾就叫這個名字**。
2. 把帳號名稱交給老師。
3. 收到 email 邀請後，點 **Accept invitation** 加入課程 repo。

## 步驟 2　打開終端機
- **Mac**：按 `⌘ + 空白鍵`，輸入 `Terminal`，按 Enter。
- **Windows**：按開始，搜尋 `PowerShell`，打開它。

之後看到灰底的指令，就是**複製貼到終端機，再按 Enter**。

## 步驟 3　安裝 Git、Node.js、GitHub CLI

**Mac**（先裝 Homebrew，它是 Mac 的軟體商店）：
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
裝完後，照畫面最後的提示執行它給你的兩行指令，然後：
```bash
brew install git node gh
```

**Windows**：
```powershell
winget install Git.Git OpenJS.NodeJS.LTS GitHub.cli
```
裝完後**關掉 PowerShell 再重新打開**，並執行下面這行（允許 npm 在 PowerShell 裡執行，只需要做一次）：
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
出現確認提示時輸入 `Y`。

**確認安裝成功**（三行都要出現版本號碼）：
```bash
git --version
node --version
gh --version
```

## 步驟 4　登入 GitHub
```bash
gh auth login
```
依序選擇：`GitHub.com` → `HTTPS` → `Yes`（用 GitHub 帳密登入 Git）→ `Login with a web browser`。終端機會顯示一組代碼，貼到瀏覽器裡就完成了。

再設定你的名字（用英文或拼音）：
```bash
git config --global user.name "你的GitHub帳號"
git config --global user.email "你註冊GitHub的email"
```

## 步驟 5　安裝 Claude Code
**Mac**：
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
**Windows（PowerShell）**：
```powershell
irm https://claude.ai/install.ps1 | iex
```
裝完後**開一個新的終端機視窗**，確認：
```bash
claude --version
```
> 使用 Claude Code 需要 Claude 付費方案（Pro 以上）或老師提供的帳號。官方安裝說明：https://code.claude.com/docs/en/quickstart

## 步驟 6　把星球下載到你的電腦
```bash
cd ~
gh repo clone <老師的帳號>/<repo 名稱>
cd <repo 名稱>
npm install
```
> `cd` 是「進入資料夾」，`~` 是你的使用者資料夾。這一步會在裡面建立一個專案資料夾。

## 步驟 7　啟動 Claude Code
```bash
claude
```
第一次會請你在瀏覽器登入。登入後，Claude Code 會先跟你打招呼，列出你的**市長任務進度**，並告訴你下一步要做什麼。跟著它的引導走就好，或直接輸入：
```
/new-city
```
它會問你幾個問題，幫你在星球上領一塊地、建好自己的城市。之後每次打開 Claude Code，它都會接著上次的進度引導你；隨時輸入 `/mission` 也能看進度。

🎉 完成！下一步：[01 建立你的城市](./01-建立你的城市.md)

### 常見問題
| 狀況 | 解法 |
|---|---|
| `command not found` 或「無法辨識」 | 關掉終端機重新打開；還是不行就重新安裝那個工具 |
| `npm install` 很久 | 正常，第一次要 1–3 分鐘 |
| 每次打開終端機都要重新 `cd` 嗎？ | 是。`cd ~/<repo 名稱>` 再 `claude` |
| Windows 出現「因為這個系統上已停用指令碼執行」 | 執行步驟 3 的 `Set-ExecutionPolicy` 那一行 |
| 想離開 Claude Code | 輸入 `/exit` |
